# VESM 3. Lokaverkefni:

## Skýrsla 
Verkefnið okkar var að búa til Iot-vekjaraklukku sem hjápar notanda að vakna. Vekjaraklukkan er með speaker sem spilar hátt hljóð þegar vekjarinn fer í gang.

Takkinn sem slekkur á vekjaranum á að vera  hinum megin í herberginu frá vekjaraklukkunni. Notandinn þarf því að fara úr rúmi og fara að takkanum til að slökkva á vekjaranum.
